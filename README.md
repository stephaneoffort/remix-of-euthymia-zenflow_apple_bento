# ZenFlow

ZenFlow est une application de gestion de projets, de tâches et de collaboration d'équipe :
espaces multi-équipes, kanban, calendrier, chat, notes rapides et intégrations (Google, Notion, Figma, Zoom…).

## Développement

```bash
bun install
bun run dev
```

Le backend (base de données, authentification, fonctions, stockage) est géré via Lovable Cloud.
